# QuietChat · 一隙

打开微信时，先别让聊天列表替你决定注意力去哪。

QuietChat 是一个 macOS 菜单栏小工具。打开微信电脑版时，它用一块遮罩盖住左侧聊天列表；想看全部聊天时输入密码解锁，关掉微信窗口后自动重新锁定。它要做的是在"随手打开微信"和"被无关消息吸走注意力"之间加一点阻力，不是一把真正的锁。

## 为什么做它

每次打开微信，注意力总会不知不觉被公众号推送勾走：本来只想回一条消息，回过神来，大把时间已经没了。

公众号里的内容我并不排斥，想看的时候完全可以主动去看。我不愿意的是，每次打开微信都被动地把注意力交出去。QuietChat 就是为此留的"一隙"：先挡住，要看时再主动打开。

## 功能

- **遮住聊天列表**：遮罩跟随微信主窗口移动、缩放、切换桌面；其他应用的窗口压上来时自动让出，不挡住它们。
- **密码解锁**：在遮罩上的密码框输入密码解锁。输入默认明文显示，可以切换为隐藏，并记住你的选择。
- **自动锁定**：关闭或最小化微信窗口、隐藏或退出微信时自动锁定；也可以从菜单「立即锁定」。
- **定时强控（可选）**：与两种遮挡方式独立组合。首次原密码解锁后开始固定计时，期间再次解锁需手输明文固定 Q-M 序列，成功后不延长计时；到期恢复原密码。
- **修改与恢复密码**：解锁后可以修改密码；忘了密码时，可以从菜单恢复为默认密码。
- **白名单快捷入口（可选）**：在不透明遮罩上按名单顺序显示固定按钮，不受微信列表滚动或新消息重排影响。普通聊天自动搜索回车；「文件传输助手」仅填入搜索词，再由你点击微信「功能」卡片。全程保持锁定与列表遮挡，默认仍是整块遮挡。
- **白名单快捷入口响应速度**：分别调整打开搜索、全选旧搜索词和等待搜到结果的固定等待，默认全部为 0 毫秒。效果不佳时可选择 75／25／250 毫秒组合或自定义；选择保存后重启沿用，也可一键恢复全零基准。
- **校准**：拖动边框让遮罩对齐聊天列表，移动或缩放微信窗口后不需要重新校准。两种遮挡方式各有一套校准。
- **菜单栏图标**：锁定和解锁两种状态一眼可见。
- **外观选择**：在菜单「外观」里选择「跟随系统」「浅色模式」或「深色模式」，整个 QuietChat 界面立即切换并记住选择；默认跟随系统。
- **开机自启动**：在菜单里勾选「开机自启动」后，登录 macOS 时自动启动 QuietChat；默认关闭。
- **应用更新**：首次询问是否允许自动检查；同意后每天检查一次。发现新版本只在菜单栏图标显示小圆点，点击「安装更新」后由你确认下载安装和重启；也可以手动检查或关闭自动检查。

## 工作方式与隐私

- 不修改、不注入微信，只是在微信窗口上方显示一个遮罩窗口。
- 更新检查和下载安装包时访问 GitHub 及其下载服务；未同意自动检查时不发后台更新请求。聊天内容、白名单、密码和校准配置不会上传，不上报系统信息。遮罩与快捷入口本身不联网。
- 辅助功能权限用于跟踪和聚焦微信主窗口；快捷入口还会核对系统的键盘合成访问，只向目标主窗口发送搜索按键，不改写剪贴板。
- 两种方式都不截图、不运行 OCR，不申请屏幕录制或输入监听权限。曾授予的屏幕录制权限可以撤销，不影响新方式。操作日志不记录名称、搜索词或聊天内容。
- 程序核对窗口焦点，不读取搜索结果或当前聊天身份。普通名称需能通过「⌘F → 完整名称 → 回车」直接打开；重名、多个结果或无结果不会自动消歧，指令执行结束也不代表已验证打开成功。微信更新可能改变搜索行为。
- 修改后的密码只保存加盐哈希（PBKDF2-SHA256），不保存明文。配置文件位于 `~/Library/Application Support/QuietChat/config.json`。

**它是阻力，不是锁**：⌘F 搜索、点通知跳转、打开独立聊天窗口、直接退出 QuietChat 等方式都能绕过遮罩。这是有意的取舍，目的是打断"随手一刷"的惯性，而不是防住自己。

## 系统要求

- macOS 14 及以上
- 键盘路径在微信 4.1.13（269602）、macOS 26.5 上验证，包含搜狗拼音中文模式；其他版本尚未验证
- 从源码构建需要 Xcode 26 及以上

目前只支持 macOS，同时支持 Apple 芯片和 Intel 芯片。

## 下载安装

1. 到 [Releases](https://github.com/OumCc/quiet-chat/releases/latest) 下载 `QuietChat-x.y.z.dmg`，打开后把 QuietChat 拖进「应用程序」。
2. 安装包没有经过 Apple 公证，第一次打开时系统会拦住它，提示无法验证是否包含恶意软件。先关掉提示，到「系统设置 → 隐私与安全性」，在页面底部找到 QuietChat，点「仍要打开」并确认。
   也可以在终端里移除隔离标记，然后正常打开：
   ```bash
   xattr -dr com.apple.quarantine /Applications/QuietChat.app
   ```
3. 继续[首次使用](#首次使用)的步骤。

**更新**：首次使用时可以允许或拒绝自动检查，之后从菜单「自动检查更新」切换。「检查更新…」随时可用；「下载安装包…」保留手动入口。后台发现新版本不会弹窗抢焦点，点击更新入口后才能下载和安装。安装会退出并重启 QuietChat，暂时停止遮罩，请先保存白名单修改并结束校准。只读安装包中的应用需先复制到「应用程序」再更新。安装需要管理员授权时由系统提示，你可以取消。

**旧版本用户**：1.1.0 之前的版本没有更新器，需要先手动安装一次 1.1.0，之后才可通过客户端升级。

**升级后授权失效**：安装包使用临时签名，升级后辅助功能权限可能失效。检测到新构建且所需权限缺失时，应用会提示一次并提供设置入口。在「系统设置 → 隐私与安全性 → 辅助功能」用「−」删掉旧的 QuietChat，再用「+」添加当前应用并开启权限。快捷入口还会检查键盘合成访问，缺失时从菜单的辅助功能授权入口处理。你的密码、校准结果和白名单不受影响；选择「稍后」仍可从菜单授权。

## 首次使用

1. 首次运行会弹出辅助功能授权提示。到「系统设置 → 隐私与安全性 → 辅助功能」里打开 QuietChat。
2. 在遮罩的密码框里输入默认密码 `1234567890` 解锁，然后点菜单栏的 QuietChat 图标，选「校准遮罩位置…」，拖动蓝框的左、右、上三条边，对齐微信的聊天列表。

想用快捷入口：

1. 解锁后在菜单里选「白名单快捷入口」，在「编辑白名单…」中每行填写完整搜索名称，有备注就填完整备注；保留内部空格、表情和标点，不使用截断标签。
2. 在当前方式下「校准遮罩位置…」，让蓝框盖住整个聊天列表；两种方式的校准独立保存。
3. 立即锁定，点击遮罩按钮。普通聊天自动搜索回车；文件传输助手填词后，按提示手动点击微信「功能」卡片。入口很多时只滚动按钮区域，底部密码框保持可用。
4. 操作期间按钮暂时禁用，密码解锁仍可用；切走、解锁或切换方式会停止后续按键。文件传输助手交接结束后切走，不会自动重放搜索，再点一次入口才重新准备。

旧配置中的 `precise` 会读取为快捷入口，正常保存时写为 `shortcuts`；名单、密码、外观和独立校准保留，配置版本仍为 1。

想调整白名单快捷入口响应速度：

1. 先选中「白名单快捷入口」，再打开菜单「白名单快捷入口响应速度」。切回「整块遮挡」时该菜单禁用；锁定时也可调整。
2. 三段默认均为 0 毫秒，不额外增加固定等待。「打开搜索」控制打开搜索后的等待；「全选旧搜索词」控制选中旧词后、输入新名称前的等待；「等待搜到结果」控制输入名称后、回车或交给你手动选择前的等待。
3. 如果搜索或打开聊天效果不好，可将三段分别改为 75、25、250 毫秒；也可按下表范围分别自定义整数毫秒。修改一段会保留另外两段。
4. 保存后的选择在重启后沿用。「恢复基准（0 毫秒）」将三段一起清零。升级到常规功能时，旧版本保存的速度设置会统一归零，此后新的选择正常保留。

| 阶段 | 默认基准 | 非零预设 | 自定义范围 |
| --- | --- | --- | --- |
| 打开搜索 | 0 毫秒 | 75 毫秒 | 0～150 毫秒 |
| 全选旧搜索词 | 0 毫秒 | 25 毫秒 | 0～50 毫秒 |
| 等待搜到结果 | 0 毫秒 | 250 毫秒 | 0～500 毫秒 |

菜单中的「固定等待合计」只是三段等待之和；实际打开聊天还包含聚焦、系统调用和微信响应，零等待不表示总耗时为零。零等待仍经过权限、焦点和取消核对。

想给再次解锁增加门槛：

1. 打开菜单「定时强控」，选择 15／30／45／60 分钟或自定义 1～1440 的整数分钟，再勾选「开启定时强控」。默认关闭、默认时长 30 分钟；开关和时长会保存。
2. 开启后下一次用原密码成功解锁才开始计时；开启时若已解锁，也等待下一次原密码解锁。重新锁定后，周期内再次解锁必须逐键输入 `qwertyuiopasdfghjklzxcvbnm` 并回车。固定序列与输入始终明文显示，不可修改，禁止粘贴、拖入和自动文本替换，可以退格或移动光标纠错。
3. 遮罩显示剩余时间，菜单打开时更新状态。Q-M 解锁不延长计时；到期恢复原密码输入及原显示偏好，下一次原密码成功解锁开启新一轮。到期只切换输入要求，不改变当前锁定状态。
4. 周期内关闭或修改时长，需要在弹窗中同样手输 Q-M 确认；确认不解锁遮罩。修改成功从保存时重新计时，选择当前时长、取消或保存失败均不重置周期。
5. 睡眠计入时长；切换遮挡方式、使用白名单入口、微信关闭或重开不重置周期。退出并重开 QuietChat 会清除本轮计时，保留开关及时长，重新等待原密码解锁触发。

建议解锁后尽快在菜单里「修改密码…」。忘了密码时，选菜单里的「恢复默认密码…」即可，锁定状态下也能用；修改或恢复原密码不会结束正在进行的强控周期。

## 从源码构建运行

用 Xcode 打开 `macos/QuietChat.xcodeproj`，选择 `QuietChat` scheme，按 ⌘R 运行。也可以用命令行：

```bash
xcodebuild -project macos/QuietChat.xcodeproj -scheme QuietChat -configuration Debug -derivedDataPath macos/build build
open macos/build/Build/Products/Debug/QuietChat.app
```

然后按[首次使用](#首次使用)的步骤授权和校准。

### 应用版本

根目录的 [Version.xcconfig](Version.xcconfig) 是 macOS 应用版本的统一来源。升级时修改其中的 `MARKETING_VERSION`，本地 Debug、Release 和 GitHub Actions 构建都会使用该值，菜单显示当前应用包里的版本。

发布时推送对应的稳定版本 `v<版本号>` tag，例如 `v1.1.0`；tag 与文件版本不一致时，发布流程会报错停止。手动触发构建也使用文件版本，构建号继续由 GitHub Actions 运行编号提供。

自动更新使用固定 EdDSA 密钥验证安装包和清单；正式 tag 构建必须配置 `SPARKLE_ED25519_PRIVATE_KEY`。流水线验证全部资产后先上传草稿，再公开 GitHub Release；手动触发仅构建 DMG，不需要私钥。密钥配置与验证步骤见 [发布与更新](docs/releases.md)。

### 重新编译后授权失效？

默认使用本机临时签名。每次重新编译签名都会变，系统会把它当成新应用，辅助功能和键盘合成访问可能随之失效。

- **根本解决**：把 `macos/Configs/Local.xcconfig.example` 复制为 `Local.xcconfig`，按里面的说明填写一个固定的签名身份（免费 Apple ID 的开发证书，或自建证书都可以）。
- **临时办法**：在辅助功能列表里用「−」删掉 QuietChat，重新运行后再授权一次。
