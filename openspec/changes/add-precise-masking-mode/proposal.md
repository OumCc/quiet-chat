# 变更提案

## 审阅摘要

- 为什么现在做：v1.0.0 只有整块遮挡。想用"文件传输助手"这类少数聊天时也得先解锁，而一解锁全部聊天都露出来，又回到了分心的起点。用户决定放弃 M3 快捷入口，直接做精准遮挡（S-01）。
- 目标结果：新增"精准遮挡"模式。锁定时只露出白名单聊天所在的行，可以直接点击，其余照旧遮住。默认仍是整块遮挡，已有用户不受影响。
- 范围与不做什么：只做 macOS；白名单按聊天名称定义。不做快捷入口，不按置顶识别，不做黑名单、Windows 版和通用设置窗口。
- 验收标准：默认行为不变；菜单可以切换且重启后保持；白名单行露出并可点击；列表变化时 0.3 秒内重新盖住，悬停不算变化，点击选中后已露出的行短暂盖住再露出；白名单为空或缺少屏幕录制权限时整块遮住；密码框固定在底部遮挡条；两种模式各自校准；不保存截图，日志不记录聊天名称。
- 待确认风险：读取画面期间持续占用 CPU，内容变化后最坏约 0.27 秒才盖住，贴着 0.3 秒的上限（D-017）；取图方式只在 macOS 26.5 上验证过；真实截图下的识别准确率（浅色模式、长名称尚未充分验证）；macOS 可能定期要求重新确认屏幕录制权限；发布包是临时签名，升级后要重新授权；Q-011 的闪动优化尚未决定，决定前按 D-003 执行。

## 已确认变化

- 遮挡方式分为"整块遮挡"和"精准遮挡"，默认整块遮挡；菜单单选切换，锁定时也能切换（D-004、D-005、D-011）。
- 精准遮挡按白名单名称露出对应的行，名称匹配遵循 D-002，截断的判定按 D-013；识别不出或匹配不上的行保持遮住（D-001、D-002、D-009、D-013）。
- 列表内容变化时先把已露出的行全部盖住，画面稳定、识别完成后再露出；滚动时立即盖住。悬停不算变化；点击选中一行按内容变化处理（D-003、D-012、D-014）。
- 精准遮挡下，密码框固定在列表栏底部一条始终遮住的区域（D-006）。
- 白名单通过菜单"编辑白名单…"打开的窗口维护：需要先解锁，只在精准遮挡下可用；第一次切到精准遮挡、名单为空且已解锁时自动打开（D-004、D-005、D-012）。
- 两种模式各自保存校准结果；精准遮挡第一次使用时，沿用整块遮挡的左右边界，上边距为 0（D-007）。
- 精准遮挡需要屏幕录制权限，只在切到精准遮挡时申请；缺少权限时整块遮住，并在菜单里提示和提供授权入口（D-008、D-011）。
- 画面只在本机内存中处理：不保存截图，不联网，日志不记录聊天名称（D-011）。
- 从文档中删除 M3 快捷入口，更新 README 的功能、隐私说明和后续计划（D-009）。

## 范围

### 范围内

- 遮挡方式的选择、持久化，以及与锁定状态的关系。
- 白名单的编辑、整理和持久化。
- 精准遮挡的读取画面、识别、匹配、露出、重新遮住，以及缺少权限、白名单为空时的处理。
- 精准遮挡的独立校准和密码框位置。
- 架构文档、README 和配置 schema 的相应更新。

### 范围外

- M3 快捷入口、按置顶底色识别、黑名单模式（Q-001、S-01）。
- Windows 版的实现。
- 通用设置窗口（Q-004 的 B 选项）。
- 把真实截图作为测试样本放进仓库（D-010）。
- Q-011 的闪动优化（待用户决定）。

## 能力清单

### 新增能力

- `masking-mode`：两种遮挡方式的选择、默认值、持久化、与锁定规则的关系、屏幕录制权限的申请时机、各自的校准。
- `chat-whitelist`：白名单的编辑入口、可用条件、保存时的整理规则，以及首次使用时的引导。
- `precise-masking`：精准遮挡的露出条件、名称匹配、先遮后露、悬停与窗口移动的处理、密码框位置、白名单为空和缺少权限时的处理、隐私约束。

### 修改能力

- 无。仓库此前没有基线规格（`openspec/specs/` 为空）。整块遮挡的既有行为记录在 `docs/architecture.md` 中，本变更不改变它们。

## 影响

### 行为与用户

- 菜单新增"遮挡方式"分组（两个单选项和"编辑白名单…"）；精准遮挡缺少权限时，显示提示和"授予屏幕录制权限…"。
- 选择精准遮挡的用户需要额外授予屏幕录制权限；README 需要如实说明精准遮挡会读取聊天列表的画面。
- 不切换模式的用户感知不到任何变化。

### API 与依赖

- 新增使用系统框架 ScreenCaptureKit 和 Vision，不引入第三方依赖，不联网。
- 新增 macOS 权限：屏幕录制，只有精准遮挡需要。
- 配置格式新增三个可选字段：遮挡方式、白名单、精准遮挡的校准结果。向后兼容，`schemaVersion` 不变。

### 代码与运行

- 识别相关的纯逻辑放在可以单独测试的模块中；应用外壳新增截图、权限、白名单编辑窗口和精准遮挡流程控制；遮罩和菜单相应修改。
- 只在需要时读取画面。读取期间每 0.2 秒取一张列表栏的图，持续占用少量 CPU（D-017）；不使用持续的截图流，避免微信窗口被系统标上紫色的共享标记（D-016）。
- 文档：架构文档删除 M3、补充精准遮挡规则；README 同步更新。
