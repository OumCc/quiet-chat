# macOS 自动更新提案

## 审阅摘要

为已安装用户提供经确认的客户端升级能力，省去每次自行下载和替换 DMG。首次询问联网检查，菜单提醒，确认后安装；升级后按实际权限引导。使用 GitHub 和临时签名，首版 1.1.0；不做静默安装、公证、增量更新或自动发布本次版本。验收包括密钥验证、权限提示以及真实双版本替换重启；密钥配置和没有设备的验证项需如实记录。

## 已确认变化与范围

- 新增首次同意、每天自动检查、手动检查和持久化开关。
- 自动发现版本只标记菜单栏；标准更新窗口承接用户确认、下载和重启。
- 应用和清单经独立 EdDSA 信任链验证；发布全部资产后才公开 Release。
- 升级导致权限缺失时，提供一次性引导；保留配置、登录项和锁定行为。
- 修正“不联网”说明，限定新增网络用途，首版版本更新到 1.1.0。

## 能力清单

- `macos-app-update`：同意检查、菜单提醒、确认安装、失败保留旧版与升级权限引导。
- `signed-macos-release`：固定公钥、签名 DMG/清单、完整稳定版本发布契约。

## 影响与依据

客户端影响应用装配、菜单及权限启动提示；新增固定 Sparkle 2.10.0 依赖，使用 UserDefaults，不改变 shared/config.schema.json。分发影响现有 GitHub Actions 与首次密钥准备。已有用户需要手动安装一次包含更新功能的版本。

依据 research.md 的现状证据及 Q-001～Q-005；用户已明确批准实施。
