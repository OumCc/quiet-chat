# 变更提案

## 审阅摘要

- 为什么现在做：精准遮挡把操作入口绑定到微信当前可见的白名单行；滚动后没有可露出的行时，遮罩也拦住后续滚动，用户失去恢复入口。
- 目标结果：默认保留「整块遮挡」，第二种方式替换为「白名单快捷入口」。白名单按钮固定显示在遮罩上，点击后通过微信搜索进入聊天，原聊天列表继续遮住，锁定状态不变。
- 范围与不做什么：只做 macOS 的可点击按钮、键盘搜索与文件传输助手特例；不新增全局快捷键、结果 OCR、可配置宏、聊天身份消歧、联网或 Windows 功能。
- 验收标准：入口不受原列表滚动和重排影响；普通聊天自动搜索回车；文件传输助手自动填入完整搜索词后，由用户点击微信功能卡片进入聊天。操作不解锁、不露出真实列表；不申请录屏权限；已有名单和通用设置保留，整块遮挡及窗口避让回归通过。
- 风险与审阅状态：原文件传输助手自动导航门禁失败，用户决定改为搜索交接（D-008）；本次修订已明确批准（research S-14）。修订 V-001～V-003 及生产交互、取消和保留功能回归已通过，验证记录见 tasks。没有聊天打开回执，不把填词或指令发送完成当作目标已验证打开。

## 已确认变化

1. 用「白名单快捷入口」替换第二种方式，不继续提供「精准遮挡（只露出白名单）」作为运行模式（D-001）。
2. 白名单的职责从识别与露出规则变为静态入口配置；按钮按配置显示，与原聊天在列表里的位置无关（D-001、D-002）。
3. 普通聊天通过「聚焦微信主窗口 → ⌘F → 输入完整名称 → 回车」打开；完整名称「文件传输助手」使用内置搜索交接分支：填词后结束自动任务、恢复按钮并提示用户点击微信「功能」卡片，不发送方向键、回车或自动点击（D-002、D-008）。
4. 打开操作保持锁定和不透明遮罩；取消持续截图、OCR 及录屏授权流程，保留辅助功能授权（D-004）。
5. 名单编辑限制、默认方式、独立校准、密码、自动锁定、外观和窗口跟随继续按现有规则执行（D-005）。

## 范围

### 范围内

- 模式切换、旧精准方式的兼容读取、既有名单和通用设置保留。
- 遮罩上的白名单按钮、名称完整输入、操作忙碌与取消、可检测错误。
- 普通聊天搜索提交路径及文件传输助手的搜索交接特例。
- 原运行时识别链路及因替换而失去消费者的依赖退役。
- 文档、配置契约、聚焦验证和原有功能回归。

### 范围外

- 全局键盘绑定、用户自定义脚本、鼠标坐标定位或剪贴板兜底。
- 名称以外的聊天标识、重名消歧、结果排序控制或打开成功的内容验证。
- 聊天预览、未读提示、截图识别回退、进程注入、数据库读取及联网。
- 旧 OpenSpec 归档及旧任务勾选修正。

## 能力清单

### 新增能力

- `masking-mode`：目标版本的两种方式、默认值、切换与锁定、旧模式迁移、独立校准及权限边界。
- `chat-whitelist`：名称名单的编辑、整理、持久化与完整搜索名称要求。
- `whitelist-shortcuts`：固定按钮、普通聊天自动打开与文件传输助手手动选择的搜索准备、生命周期、操作取消及反馈边界。

### 修改能力

无已发布的基线规格。`openspec/specs/` 当前为空，因此本变更以 `ADDED Requirements` 建立上述目标能力；行为层面替换已有精准遮挡，不创建引用不存在基线的 `MODIFIED` 或 `REMOVED` 条目（D-007）。

## 影响

### 行为与用户

原精准方式用户改为从固定按钮进入聊天，白名单不再随原列表滚走。已有名称继续用于入口；应填写能在当前微信搜索中打开目标的完整名称。重名、多个匹配或找不到结果时，系统不承诺自动识别出唯一目标，用户可按既有密码规则解锁后自行处理。

### API 与依赖

没有后端 API。键盘操作使用系统事件接口，不引入第三方依赖；微信自身搜索由当前客户端处理。QuietChat 不读取画面、不申请录屏权限、不验证搜索结果身份，也不宣称限制微信自身的搜索范围。

### 代码与运行

复用窗口跟踪、遮罩和白名单编辑；新增按键操作协调与主窗口焦点交接。退役截图/识别装配及其专用依赖。通用密码、外观、窗口跟随、其他窗口避让、自动锁定和开机自启动列入回归。

### 与旧变更的关系

本变更替代 `add-precise-masking-mode` 中继续建设实时白名单识别与开洞的计划。现有源码是迁移基线；旧变更文件及已记录的验证保留作历史，不据未勾选任务重做已有代码，也不并行实施旧精准路线（D-006）。

## 证据与决策

- [research.md](research.md)：S-02～S-06 用户讨论和图片；当前实现；系统接口依据；实施前技术门禁。
- D-001：默认整块遮挡，第二种方式改为固定白名单入口。
- D-002：普通聊天搜索回车。
- D-008：替代原 D-003，文件传输助手只准备搜索、由用户手动选择；不追踪用户点击或自动重放，自动任务结束不抢回微信焦点。
- D-004、D-005：不解锁、不录屏，继承编辑、校准和通用行为。
- D-006、D-007：保留旧研究历史，以现有源码为基线，目标规格使用 ADDED。
- V-001～V-003：修订后的搜索交接、Unicode 输入及聚焦稳定性必须在实施前验证；若遮罩妨碍手动点击则停止并澄清，没有隐含的识别、坐标或隐藏遮罩兜底。
