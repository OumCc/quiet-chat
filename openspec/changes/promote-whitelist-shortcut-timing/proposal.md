# 变更提案

## 审阅摘要

- 原因：用户已实测全零等待可用，希望将测试菜单转为常规速度设置。
- 结果：菜单改名，默认全零，仅保留一组非零预设及自定义，升级后旧速度统一归零。
- 边界：菜单、速度配置、测试与说明；搜索路线、权限及取消行为沿用。
- 验收：迁移只影响速度，后续选择持久化；Core、菜单、构建与规格校验通过。
- 风险与待确认：微信响应可能随环境变化，保留非零组合和原范围自定义；无待确认项。

## 已确认变化

1. 入口改为「白名单快捷入口响应速度」，保留阶段子菜单、合计及恢复基准；阶段只提供 0 基准、75／25／250 对应预设、自定义。
2. 默认及错误字段回退为零，自定义上限继续为 150／50／500；只在 shortcuts 方式可调整，锁定时也可用。
3. 旧速度选择全部重置，正常保存标记后保留后续选择，不改变其他有效配置与配置总版本。
4. README 改为常规使用说明，解释等待作用与效果不佳时的调整方法。
