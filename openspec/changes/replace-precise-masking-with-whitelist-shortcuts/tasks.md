# 实施任务

## 审阅摘要

- 实施目标：落实 masking-mode、chat-whitelist、whitelist-shortcuts，使用静态按钮与键盘搜索替换原精准遮挡；普通聊天自动回车，文件传输助手填词后交给用户点击功能卡片。
- 依赖顺序：本机技术门禁 → 配置兼容与操作状态 → 主窗口聚焦和按键协调 → 遮罩 UI → 装配与旧链路退役 → 文档 → 构建和回归。
- 完成定义：修订后的三项技术门禁及全部任务完成，普通聊天自动打开、文件传输助手搜索交接和取消行为实测通过，原功能回归通过，运行时没有截图/OCR/录屏授权依赖；旧配置不丢数据。
- 最终验证集合：Swift 现有包测试；Xcode Debug/Release 构建和启动冒烟；支持微信版本的交互验收；整块遮挡/窗口避让/锁定/外观/独立校准回归；OpenSpec status 与严格校验。
- 当前状态：全部任务已完成。D-008 搜索交接修订获批（research S-14），Q-007 为 ANSWERED，原自动导航失败记录保留；54 项包测试、Debug / Release 构建启动、生产交互与取消、保留功能回归及 OpenSpec 严格校验通过，最终 diff 已审阅。

## 实施阶段验证记录

- 测试：`swift test --package-path macos/QuietChatCore --disable-automatic-resolution` 通过 54 项、10 个 suite；其中配置/名单聚焦测试通过 18 项，操作编号通过 3 项，覆盖重复开始与取消后旧 finish 不影响新操作。不安装或迁移依赖。
- 构建：现有 QuietChat scheme 的最终 Debug / Release 均 BUILD SUCCEEDED，禁用自动包解析、输出至临时 DerivedData；签名只读核对通过。两版启动的真实遮罩和控件通过工具及用户确认，无新崩溃。唯一警告为未依赖 AppIntents 而跳过元数据提取；启动冒烟前后原配置字节摘要一致。
- 生产路径：微信 4.1.13（269602）、macOS 26.5，无 QuietChat 录屏授权。用户确认普通入口进入真实目标、聊天编辑框为空；文件传输助手卡片分别位于网络建议上方和下方时均可手动点击进入真实聊天，无网络提交或消息发送。原列表滚出目标、快速连续点击、切走后无自动聚焦/重放通过，锁定和不透明遮罩保持。
- 已有搜索词：原生弹窗覆盖按钮时鼠标不能点击，用户接受原生避让；Esc 会清空旧词。通过实际按钮的辅助功能动作触发生产路径，用户看清旧词完整替换、没有拼接，并进入普通目标。此项仅为辅助功能触发验证，不声称鼠标穿透弹窗，未增加自动关闭弹窗行为。
- 密码焦点：生产验收曾发现输入误落入微信，失败轮不计通过，用户手动清除误入内容。移除直接 resignKey，补充两种密码控件用户点击时的公开 makeKey 和取消通知。最终用户确认隐藏/明文两种输入、普通搜索后重新点击追加、草稿保留均正常，微信编辑框为空，锁定与遮罩保持。
- 有效取消：切其他应用 / 独立微信窗口分别在 245 / 273 ms、opening-search 后停止；解锁入口复测有 658 ms 的输入前取消及实际解锁记录；隐藏 / 关闭主窗口分别在 263 / 748 ms 停止；打开 QuietChat 菜单后 831 ms、awaiting-results 中取消，再切 full。有效轮均无后续提交，用户确认无消息；取消后能重新主动搜索。工具或人工切换发生在 finished 后的轮不计通过；自己菜单打开取消使用 menuWillOpen，不修改生产时序。
- UI 与权限：最新实际 MaskView 的离屏检查通过名单顺序、完整回调、21 个入口溢出、忙碌禁用、窗口洞隐藏/恢复、反馈、校准/full/空名单场景；未显示窗口、读取配置或操作微信。用户确认上层窗口点击不被拦截、移开后恢复，浅色/深色/跟随系统一致且保留测试草稿。操作日志核对不含配置名称，只含阶段、耗时和错误码；运行时无截图/OCR/录屏调用、悬空 Detection 引用，工程 plutil 校验通过，历史 tools/probe 未修改。
- 保留行为：用户确认整块遮挡居中控件、错误密码清空与提示、正确密码解锁、最小化/隐藏/关闭后的自动锁定、窗口移动/缩放和已有桌面跟随。三次自动锁定有日志佐证；密码验证与登录项注册实现与基线一致。
- 独立校准与配置：快捷入口不移边完成校准，仅保存 preciseListColumn；整块遮挡拖动后取消，原 listColumn 保持。日志与只读快照核对通过，名单、密码记录和 schemaVersion 保留；用户选择后当前为 shortcuts / system / 隐藏输入。开机自启动菜单只读观察与原状态一致，未切换登录项或执行系统重新登录测试。
